# whereisyoursound

Портфолио Наты – основательницы whereisyoursound, звук для кино, рекламы, анимации и игр.
Статический сайт без фреймворков и сборки: HTML, CSS и немного JS. Работает на любом хостинге.

## Структура

```
index.html              страница
assets/css/style.css    стили
assets/js/data.js       ВСЕ ТЕКСТЫ, КАТЕГОРИИ, ПРОЕКТЫ И БРЕНДЫ – правится здесь
assets/js/main.js       логика: языки, тема, курсор, бегущая строка, окна категорий
assets/fonts/           шрифт Raleway, лежит локально – без Google Fonts
assets/video/           короткие превью-петли для плиток категорий
assets/img/             постеры и иконка
```

## Как добавить видео

1. **Превью категории** (бегущее видео в плитке): петля 3–5 секунд без звука, mp4 (H.264), около 1 МБ.
   Положить в `assets/video/`, постер (webp/jpg) – в `assets/img/`, и указать пути
   в `assets/js/data.js` в полях `preview` и `poster` нужной категории.
2. **Полный ролик**: загрузить в Kinescope, взять ID из ссылки (`kinescope.io/<ID>`)
   и вставить в поле `kinescope` проекта в `assets/js/data.js`.

Превью можно сделать скриптом (нужен ffmpeg): `tools/make-preview.sh исходник.mov 00:00:12 commercial` –
вырежет 4 секунды с 12-й, сожмёт до ~1 МБ, сгладит стык петли и сделает постер.

Все превью на экране играют одновременно; ушедшие за край экрана ставятся на паузу и продолжают с того же места.
В фоновой вкладке, при режиме экономии трафика и при «уменьшении движения» видео не крутятся – показываются постеры.
Полные ролики грузятся только по нажатию Play.
